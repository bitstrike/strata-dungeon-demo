write a professional AAA style html/javascript dungeon crawler that uses a user uploadable ascii text file (maze1.txt) for a map with 80x80 squares. walkable areas are clear spaces while solid walls are '▓' and doors are ░. stairs going up are '╧' and stairs down into the maze are '╤' the player start location and direction is designated by '^' facing north, '>' facing east, '<facing west' and 'v' facing south.

use opengl and/or webassembly to make sure the game is performant and realistic. collision detection is of utmost importance so only process the number of squares from the user which are able to be seen by the configured torchlight radius. The player perspective is first person as they walk through the map. The player carries a small torch that lights up only 3 squares around them with light receeding in brightness the further away it gets. every 6 blocks will be a small wall torch lighting the maze. The small torches work like the player torch but only cast light 2 squares away. The lighting area of the torches is configurable in the game settings.
